Algorithm Characteristics (SIMPLIFIED)
================================================================================
EQL (Equation Learner) is a neural network-based symbolic regression method.
Key features of SIMPLIFIED run:
  • Uses JAX for automatic differentiation
  • Learns symbolic expressions through gradient descent
  • Enabled functions: id, mul ONLY (minimal polynomial set)
  • Addition/subtraction implemented via network weights
  • Grid search over regularization and layers only
  • Much faster than full function set (fewer configurations to test)

================================================================================
Comparison: SIMPLIFIED vs FULL Function Set
================================================================================
SIMPLIFIED (id;mul):        9 configurations (3 reg × 3 layers × 1 function set)
FULL (with sin,cos,etc):   54 configurations (3 reg × 3 layers × 6 function sets)

Expectation:
  • SIMPLIFIED: Faster training, simpler models, potentially cleaner equations
  • FULL: Slower training, more complex search space, risk of overfitting

Since Lorenz equations only need polynomial terms (x, y, z, xy, xz),
the SIMPLIFIED version should perform equally well or better.
