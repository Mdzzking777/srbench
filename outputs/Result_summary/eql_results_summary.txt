Algorithm Characteristics
================================================================================
EQL (Equation Learner) is a neural network-based symbolic regression method.
Key features:
  • Uses JAX for automatic differentiation
  • Learns symbolic expressions through gradient descent
  • Enabled functions: sin, cos, exp, log, sqrt, div, mul
  • Addition/subtraction implemented via network weights
  • Grid search over regularization, layers, and function sets
